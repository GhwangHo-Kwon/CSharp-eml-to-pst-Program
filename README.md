# CSharp-eml-to-pst-Program
C# eml file to pst file transfer program

## 제작 이유

1. 회사 업무 중 사내 Email의 용량 부족
2. 용량 부족으로 인해 메일 삭제하기에, 이후 업무에 필요한 메일은 따로 보관해야함
3. 메일 백업을 위해 MicroSoft OutLook 메신저 프로그램 사용
4. Outlook에서 사내 메일 계정을 Pop계정으로 등록 시 메일 수신함에 있는 메일만 백업됨
5. 업무에 맞게 메일함을 나누었는데, 그 폴더에 있는 메일들은 자동 백업이 안됨
6. 메일보관함에 백업 기능을 이용하였는데, .eml 파일로 메일 1개당 1개씩 저장됨
7. Outlook에 한번에 메일 파일을 넣기 위해 .pst 파일로 전환을 해야해서 해당 프로그램 제작
