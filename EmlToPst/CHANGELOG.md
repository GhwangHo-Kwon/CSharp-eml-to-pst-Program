# 변경 사항

## 웹메일 백업

- `Address:Port`, SSL/TLS 기본값의 IMAP 백업 탭 추가.
- 로그인 후 전체 개인 메일함과 하위 폴더 조회, 메일함 선택, 계정별 EML 저장.
- 읽기 전용 접근. 서버 메일을 삭제하거나 읽음 상태를 변경하는 명령은 사용하지 않음.
- 메일별 UIDVALIDITY/UID, 크기, SHA-256, InternalDate, 발신 일자, 플래그와 키워드를 SQLite에 저장.
- 완료 파일도 SHA-256을 다시 검사한 뒤 건너뜀. 손상 파일은 `.previous_*`로 보존 후 다시 다운로드.
- 임시 파일 → 검증 정보 확정 → 최종 파일 이름 변경 → 완료 기록 순서로 저장. 강제 종료 후 staged 파일 복구.
- 일시적인 통신 오류에는 2/5/10초 간격으로 최대 3회 재접속. 재접속 후 UIDVALIDITY 재검사.
- 미완료 메일은 다음 백업에서 다시 시도. 서버에서 사라진 메일과 메일함 조회 실패를 별도 표시.
- 다운로드용 MailKit 원문 버퍼를 임시 파일로 만들어 큰 메일의 메모리 사용을 줄임.

## 기존 PST 변환 연결

- 백업 탭의 **PST 변환에 사용** 버튼으로 백업 EML 경로를 기존 변환 탭에 전달.
- 백업 DB가 있는 EML은 원문 SHA-256을 확인한 뒤 원본 서버 메일함 이름으로 PST 폴더 생성.
- IMAP InternalDate를 PST 수신 일자로 적용. 일반 EML의 기존 Received 헤더 해석은 유지.
- 읽음/안 읽음과 임시보관 상태 반영. 저장된 PST를 다시 읽어 수신 일자·읽음 상태·첨부 바이트 검증.
- 사용하지 않는 Aspose.Email 참조와 EmlToMsgConverter 제거. 실제 사용 중인 OfficeIMO.Email 변환 경로 유지.

## 실행 전체 로그

- `ImportLog`를 작업마다 만들던 구조에서 애플리케이션당 하나로 변경.
- 앱 생성 시 `APP_START`, 창 표시 `APP_READY`, 종료 요청, 창 종료, `APP_EXIT` 기록.
- 메일함 조회·백업·PST 변환·취소·오류가 같은 실행 로그에 계속 누적.
- 동시 기록 보호, 줄 단위 즉시 Flush, 밀리초/프로세스 ID/고유값으로 파일명 충돌 방지.
- 기본 위치는 실행 파일 옆 `Logs`. 쓰기 불가 시 `%LOCALAPPDATA%\EmlToPst\Logs` 사용.
- 비밀번호는 파일에 저장하지 않으며 작업 중 오류 메시지에 포함되더라도 로그/오류 목록/DB에서 마스킹.
- UI 미처리 예외, 프로세스 미처리 예외, 미관측 Task 예외 기록.
- 작업 중 창 닫기는 취소 요청 후 파일 정리와 작업 종료를 기다림. 새 작업 시작은 막음.

## 검증

- `Tests/BackupRegression`에 네트워크를 사용하지 않는 13개 회귀 시나리오 추가.
- `Build.ps1`에서 WPF 빌드 및 회귀 시나리오 실행. `-Publish` 지정 시 win-x64 게시 폴더 생성.
- 제공 환경에는 .NET SDK/Windows가 없어 C# 빌드와 실행은 수행하지 못함. 별도 정적 검사 결과는 `VALIDATION.md` 참고.
